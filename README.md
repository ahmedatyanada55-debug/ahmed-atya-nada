# ahmed-atya-nada
حللت بيانات رواتب 200 موظف موزعين على 7 أقسام مختلفة باستخدام Excel.

🔍 ما اكتشفته من البيانات:
•	الفجوة في الرواتب بين الأقسام وصلت لـ 3x بين الأعلى والأدنى
•	موظفو تقنية المعلومات يحصلون الاعلي متوسط راتب بفارق 21%
•	الموظفون ذوو تقييم "ممتاز" يحصلون على 20% مكافأة إضافية
•	القاهرة تضم 40% من القوى العاملة مع أعلى متوسط راتب
-	فجوة الرواتب بين الجنسين في نفس الدور حوالي 8 % 

-	المهارات المُستخدمة:
AVERAGEIF | COUNTIF | SUMIF | IF | Conditional Formatting
Dashboard Design | Gender Gap Analysis
